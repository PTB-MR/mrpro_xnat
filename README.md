# MRpro - XNAT
Run MRpro reconstructions as a docker container inside of [XNAT](https://www.xnat.org/). 

This example utilises the (ISMR)MRD raw data plugin for XNAT:

## Starting point
1. Clone this repository
2. ``` cd mrpro_xnat ```
3. Create/select a python environment (e.g. ``` conda env create -f environment.yml ```)
4. Go through ``` walkthrough.ipynb ```
